# Koryla Next.js Demo

Live A/B testing examples using [`@koryla/next`](https://koryla.com/docs/sdk-react) middleware.

- `/headline` — text change experiment
- `/hero` — design change experiment
- `/pricing` — URL change experiment

[Live demo →](https://next-demo.koryla.com) · [Docs →](https://koryla.com/docs/sdk-react)

## Setup

```bash
cp .env.local.example .env.local
# add your KORYLA_API_KEY and KORYLA_API_URL
npm install
npm run dev
```
